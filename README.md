## 🌟 核心特色一覽

- **🦊 專屬靈狐認領與三階形態進化**：幼狐 ➔ 成狐 ➔ 仙狐。飽食、心情、精力、靈力、蓬鬆度五維監控，十種沉浸互動（揉臉、投餵、梳毛、逗弄、溫泉、安睡、探險、祈福、裝扮、拍立得手帳）。
- **🏡 放置庭院與野生訪客**：擺放美味點心與遊樂道具，吸引野生狐屬訪客到訪作客，收集特產伴手禮；內建離線收益結算。
- **📖 18 種狐屬全百科生態圖鑑**：包含全球真實狐屬物種與東亞文化傳說神狐（九尾天狐、稻荷白狐、極光星狐等），具備雷達五維能力圖、棲息地快篩與狐語擬聲器。
- **☯️ 神話傳說 vs. 科學真實深度對照**：打破千年妖魔化迷思，從動物行為學、生態平衡與歷史民俗角度進行雙重視野解析。
- **💌 時空信箱與明信片遠行冒險**：派遣靈狐前往「櫻雨花見小徑」、「綠苔古木幽谷」、「雲海千星仙峰」，帶回溫暖治癒書信與風景明信片珍寶。
- **🍃 純前端 Web Audio 自然聲學生態混音器**：零外部音檔、零頻寬消耗，純演算法合成林間清風、靜謐細雨、溫暖營火、夏夜蟲鳴與五音風鈴。
- **🧘 身心放鬆冥想呼吸引導**：內建「4-4-4-4 箱式呼吸」與「4-7-8 深度安眠呼吸」，搭配視聽漣漪光圈與舒緩磬音。
- **⛩️ 靈狐智慧之殿**：包含「命定靈狐性格測驗」、「四大領域百科挑戰問答」、「剪影猜謎挑戰」與「水晶球每日神諭籤」。
- **🎨 晝夜四季動態畫布**：支援清晨、午後、黃昏、深夜 4 階段光影切換，以及櫻花、螢火蟲、落葉、飛雪四季 Canvas 粒子互動。
- **💾 本地持久化與全格式存檔備份**：支援離線自動存檔、跨日相伴天數追蹤、一鍵複製/匯出/匯入 JSON 存檔與資料防呆修補。
- **📱 PWA 跨平台離線支援**：完全相容桌面端與行動裝置，離線可用，支援一鍵安裝為獨立應用。

## 🛠️ 技術棧 (Tech Stack)

- **前端核心**：React 19, TypeScript, Vite
- **樣式與動畫**：Tailwind CSS v4, Motion (Framer Motion)
- **音訊架構**：Web Audio API (純前端自主合成，零 MP3 依賴)
- **特效系統**：HTML5 Canvas Particle System, Canvas-Confetti
- **圖標資源**：Lucide React
- **持久化機制**：LocalStorage + JSON Backup Migration Engine
- **離線規範**：PWA Service Worker + Web App Manifest

## 🚀 快速開始 (Development)

```bash
# 1. 安裝依賴
npm install

# 2. 啟動本機開發伺服器 (Port 3000)
npm run dev

# 3. 類型檢查與語法檢查
npm run lint

# 4. 生產環境打包編譯
npm run build
```
